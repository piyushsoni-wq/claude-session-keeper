claude-session-keeper

Live sessions

Sessions currently under ~/.claude/projects — these are what Claude Code itself will delete once they're older than the cleanup period shown above. "Context usage" is an estimate of how full that session's context window was on its last turn.

Backup status

Mirrors ~/.claude/projects into the backup root now, and cuts a new dated snapshot if intervalDays has elapsed since the last one. The mirror gets deletions propagated too — real protection against Claude Code's own cleanup comes from the dated snapshots below, which are never modified once written.

          timestamp so Claude Code's cleanup won't immediately delete it again.

Automation (launchd)

          
        

        

          Whether the scheduled backup job is actually loaded, and roughly when it'll next run. launchd
          itself doesn't expose an exact "next run" time for this kind of job — the estimate below is
          computed from the last completed run plus the interval, not a guarantee (sleep/wake can shift
          it). "Install / reinstall" is safe to click any time — it re-renders the launchd job file and
          reloads it.
        

        

        

      


      

        

          
Cleanup period

        

        

          cleanupPeriodDays in ~/.claude/settings.json — Claude Code's own
          setting for how old (by last-modified time) a session can get before it deletes it on
          startup. This edits that file directly; a timestamped backup copy is kept before every change
          in case something needs to be undone.

Resume-brief summaries

          
        

        

          Each summary is generated by running claude -p locally (no API key — same
          auth as your normal Claude Code sessions) once per session, to produce a short "resume
          brief" you can search later instead of re-reading a whole raw transcript. "Summarize all"
          runs one such call per live session, sequentially — real usage against your plan,
          same as any other Claude Code session. You'll be asked to confirm the count before it runs.
